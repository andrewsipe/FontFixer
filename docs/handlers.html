Handlers

Four table-focused tidy-ups. When more than one is enabled, they always run in this order — not the order you typed them.

  1. os2 Upgrade OS/2 to version 4; set installable embedding; detect monospace; enable USE_TYPO_METRICS. The WWS bit is left unchanged (name-table claim this tool does not verify). Resolves sxHeight / sCapHeight via cmap (x / H) with uni-name fallbacks. Runs first because style depends on OS/2 v4.
  2. style Sync italic/bold angles and flags across post, hhea, OS/2, head, and CFF ItalicAngle.
    • Angles — median of uppercase stem-glyph samples via cmap (H/I/N, with uniXXXX fallbacks). Samples below a 2° floor are ignored; dominant sign preferred. Named italics keep a non-zero post angle when measurement is weak. Non-zero roman angles are allowed.
    • Italic / oblique bits — follow name labels only. Measured slant does not mark a Roman as italic. Bold weight (700 / “Bold”) stays intentional.
    • macStyle — clears only bold/italic bits (does not zero the whole field).
    Meant to run after os2. Family-relative flag advice is a separate post-pass — see Family slant.
  3. glyph Ensure .notdef is drawn; ensure non-breaking space (U+00A0) matches space width. Independent of the others.
  4. kern Remove the legacy kern table when GPOS advertises kern or vkrn (not merely when any GPOS table exists). Independent.

Family slant review

After a normal interactive run that includes style, FontFixer surveys families by measured italic angle and may recommend italic/oblique flag fixes when upright vs slanted clusters disagree with current bits. Prompt: Apply all / Review each / Quit. Incomplete, roman-only, or ambiguous families are skipped; angles are not rewritten.

Selecting handlers

--handlers and --skip-handlers are mutually exclusive. Names are comma-separated. Selection is filtered back into canonical order (os2 → style → glyph → kern).

fontfixer --handlers os2,style fonts/
fontfixer --skip-handlers kern fonts/

Out of scope

  • Name tables — use FontNameID (the old name handler was removed in 1.1.0).
  • Vertical metrics — use ebrium.
  • Glyph outlines / advances — not modified beyond the glyph tidy-ups above.
Single pass. Each font is opened once, all selected handlers run, then the font is written once (unless validate-only / dry-run). Family slant review is a separate interactive step afterward.
