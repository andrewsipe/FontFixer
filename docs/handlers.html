Handlers

Four table-focused tidy-ups. When more than one is enabled, they always run in this order — not the order you typed them.

  1. os2 Upgrade OS/2 to version 4; set installable embedding; detect monospace; enable USE_TYPO_METRICS and WWS-related consistency. Runs first because style depends on OS/2 v4.
  2. style Sync italic/bold angles and flags across post, hhea, OS/2, and head. Meant to run after os2.
  3. glyph Ensure .notdef is drawn; ensure non-breaking space (U+00A0) matches space width. Independent of the others.
  4. kern Remove the legacy kern table when GPOS kerning is present. Independent.

Selecting handlers

--handlers and --skip-handlers are mutually exclusive. Names are comma-separated. Selection is filtered back into canonical order (os2 → style → glyph → kern).

fontfixer --handlers os2,style fonts/
fontfixer --skip-handlers kern fonts/

Out of scope

  • Name tables — use FontNameID (the old name handler was removed in 1.1.0).
  • Vertical metrics — use ebrium.
  • Glyph outlines / advances — not modified beyond the glyph tidy-ups above.
Single pass. Each font is opened once, all selected handlers run, then the font is written once (unless validate-only / dry-run).
