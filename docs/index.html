OpenType tidy-up, one pass

fontfixer opens each font once, runs selected handlers, and writes once. It is the structural step between naming (FontNameID) and metrics (ebrium).

In place. Fixes overwrite originals by default — no backup. Keep copies with -o DIR, inspect with --validate-only, or list only with -n. 
pipx install "git+https://github.com/andrewsipe/FontFixer.git"
fontfixer --validate-only -v fonts/
