OpenType tidy-up, one pass

fontfixer opens each font once, runs selected handlers, and writes once. Style angles are measurement-driven; italic/oblique bits follow names. An optional family slant review can recommend flag fixes after the run. Structural step between naming (FontNameID) and metrics (ebrium).

In place. Fixes overwrite originals by default — no backup. Keep copies with -o DIR, inspect with --validate-only, or list only with -n. 
uv tool install "git+https://github.com/andrewsipe/FontFixer.git"
fontfixer --validate-only -v fonts/
