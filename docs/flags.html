Flag reference

Live wording is always in fontfixer --help. This page is the scannable map.

Input

FlagMeaning
input_pathFont file or directory of fonts (required)
-r, --recursiveAlso search subdirectories

Output and safety

FlagMeaning
-o, --output-dir DIRWrite fixed fonts to DIR instead of overwriting (created if missing; not created during -n / --validate-only)
--validate-onlyOpen each font and report problems; apply no fixes
-n, --dry-runList files and handlers that would run, then exit — fonts are not opened
--no-quarantineLeave corrupted fonts in place (default: move to <input>/_quarantine/)

Fix selection (choose one)

FlagMeaning
--handlers LISTRun only these handlers, comma-separated (os2,style,glyph,kern)
--skip-handlers LISTRun everything except these handlers

Performance and logging

FlagMeaning
-j, --jobs NParallel workers (default 1; 0 = one per CPU core)
-v, --verboseVerbose output

Exit status

CodeMeaning
0All fonts OK
1Any failure, or no fonts found

Recipes

# Inspect first
fontfixer --validate-only -v fonts/

# Tidied copies, keep originals
fontfixer -o tidy/ fonts/

# Whole tree in place, all cores
fontfixer -r -j 0 fonts/

# OS/2 + style only
fontfixer --handlers os2,style fonts/

# Everything except legacy kern removal
fontfixer --skip-handlers kern fonts/
